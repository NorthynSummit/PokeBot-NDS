Learn Current Area

Purpose
Autonomously learns nearby tiles with Coverage Planner v1.
Behavior
Soft-boundary wall-rub avoidance, gap rechecks, normalized storage, original encounter handling.
Recommendation
Start with 5–10 actions until the area looks safe.

Fix Current Tile Data

Purpose
Repairs suspicious observations near the current tile.
Best for
False blocked edges caused by menus, dialogue, or battles.

Travel to Coordinate

Purpose
Pathfinds over learned graph data to a target coordinate.
Limitations
Requires known map data and stops when reality disagrees with cache.

Rebuild Map Cache

Purpose
Compacts raw probe/sweep observations into map_graph.txt.
Use after
Manual edits, cleanup, or storage repairs.
